# accentTranslator

Tools for translating everyday English into regional accents, with a mobile app called **AccentBridge**.

## Projects

| Folder | What it is |
| --- | --- |
| [AccentBridge/](AccentBridge/README.md) | Android and iOS app: a custom keyboard that converts typed English into a chosen accent, and on-device translation of incoming foreign-language messages. |

## Getting started

Open the project you want from the table above and follow its README. For AccentBridge, see [AccentBridge/README.md](AccentBridge/README.md) and the guides in [AccentBridge/docs/](AccentBridge/docs/architecture.md).

## Contributing

To add a new accent, follow [AccentBridge/docs/adding-an-accent.md](AccentBridge/docs/adding-an-accent.md).
